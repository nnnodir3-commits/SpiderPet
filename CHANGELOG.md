# Changelog

## v38.0.0 — first community-facing source release

- Built on the v36 trailing-silk hanging implementation.
- Added natural idle leg probing, scanning, small nest-rest movements and
  startle/backstep responses.
- Added raised-foreleg pre-combat threat display, lasting roughly 3.15 seconds.
- Preserved the 32 unwarped, direction-aware walk poses and two-spider battles.
- Omitted the abandoned v37 fly-hunting prototype.
- Prepared MIT licensing for original code, explicit separation of PNG rights,
  Windows build instructions, contributor guidance and tests.

This documentation/licensing distribution does not change v38 application
behavior or binary animation frames.
