SpiderPet v36 — ЎРГИМЧАК ИПДА ҲАҚИҚИЙ ОСИЛИБ ТУШИШИ

Бу версияда ипни алоҳида тушириб, кейин йиғиш эмас:
- ўргимчак уянинг юқори четидан ЎЗИ пастга тушади;
- ўргимчак ва ип бир хил шаффоф ойнада чизилади;
- ип тананинг ортидан юқоридаги уяга боғланган ҳолда чўзилади;
- пастда бироз тебраниб туради, сўнг ип бўйлаб қайта чиқади;
- пастки бурчакдаги уяда осилиш йўқ;
- уя осилиш вақтида бузилса, ип йўқолади ва ўргимчак пастга қулайди.

Ишга тушириш:
TEST_HANGING.bat — тезкор осилиш синови.
START_PREVIEW.bat — одатдаги режим.
BUILD_ONE_EXE.bat — Windows компьютерида ягона EXE йиғиш.
Дастурдан чиқиш: Ctrl+Shift+Q

Windows график ишини фойдаланувчи текшириши керак.
