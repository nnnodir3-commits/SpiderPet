# Image-source attribution and permissions — maintainer record

The project owner has chosen **not to re-investigate the 3D source model** in
this preparation step. Its licence and the texture licence therefore remain
unverified here. The 3D mesh itself is **not included** in this repository.

Before publicly distributing the bundled `walk_*.png` / `threat_*.png` files,
enter verifiable information below, or replace the asset set with original /
properly licensed images:

- Original 3D model name and source URL: **not recorded**
- Original model author: **not recorded**
- Model licence and version / permission: **not confirmed**
- Texture authors, provenance and permissions: **not confirmed**
- Permission to redistribute derivative PNG sprite frames: **not confirmed**
- Attribution text required by original author: **not confirmed**
- Verified by / verification date: **not filled**

A SHA-256 inventory of all PNG frames is available in `docs/ASSET_SHA256.csv`.

Do not treat missing metadata embedded in a PNG file as proof of ownership or
redistribution rights. If assets were fully generated from original owned
materials, record that evidence here and choose a separate asset licence, for
example CC BY 4.0, only if you control the necessary rights.
