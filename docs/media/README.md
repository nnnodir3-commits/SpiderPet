# SpiderPet repository showcase illustrations

`spiderpet-hero.png` and `spiderpet-features.png` are original presentation compositions made using SpiderPet v38 `walk_*.png` and `threat_*.png` sprite images. These are **illustrations**, not direct desktop screenshots or photos of real spiders.

**Rights:** Because their sprite source assets have unverified upstream redistribution terms, these compositions are **not covered by the MIT source-code license**. Refer to the repository root `ASSETS_LICENSE.md` and `docs/ASSET_PROVENANCE.md`.
