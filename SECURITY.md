# Security policy

SpiderPet is a small local desktop utility. It is not designed as a security boundary. Do not run binaries from unknown sources.

- Prefer inspecting the source and building a local Windows executable.
- Avoid posting full diagnostic logs publicly if they contain personal paths or identifiable information.
- Report security-sensitive issues privately to the project maintainer through a contact method they publish in the GitHub profile. No security contact address has been set yet.
- Windows SmartScreen warnings can occur for unsigned executables. Do not instruct users to disable system protections to install an unverified download.
