# SpiderPet v38.0.0 — first public-source edition

A small, lifelike jumping-spider companion for Windows desktops.

Highlights: photorealistic gait, natural idle behaviors, reactive cursor
movement, silk corner shelters, the v36 hanging-silk mechanism, two-spider
threat displays and duels, window-edge walking.

**Requirements:** Windows 10/11, Python 3.10+, Pillow, full 44 PNG animation
set. Install Pillow using `py -3 -m pip install -r requirements.txt`, then start
with `START_PREVIEW.bat`. Exit using Ctrl+Shift+Q.

**Licensing:** Original code MIT. PNGs are excluded and must not be publicly
released until upstream rights for derivatives are confirmed. See
`ASSETS_LICENSE.md` and `docs/ASSET_PROVENANCE.md`.

This archive contains sources only. An `.exe` must be built and tested on
Windows before sharing it as a compiled release.
